# my-trading-bot
Bitcoin trading bot for MetaTrader 5

## Dasturlash Studiyasi (`index.html`)

Brauzerda ishlaydigan yagona faylli kod studiyasi. Hech qanday build yoki
o'rnatish talab qilinmaydi — `index.html` ni brauzerda oching (Tailwind va
Google Fonts CDN uchun internet kerak).

To'rtta bo'lim:

- **Jonli Muharrir** — HTML / CSS / JS yozib, natijani darhol `iframe` ichida
  ko'rasiz; `console.log` xabarlari pastdagi konsolda chiqadi. Yozgan kodingiz
  brauzer xotirasida saqlanadi va sahifa yangilanganda tiklanadi.
  `Ctrl` + `Enter` — ishga tushirish. Tayyor shablonlar: hisoblagich, todo
  ro'yxati, raqamli soat, UI kartochkalar.
- **Algoritmlar** — pufaksimon saralash, ikkilik qidiruv va Fibonachchi
  ketma-ketligining bosqichma-bosqich animatsiyasi.
- **Kod Shablonlari** — Python, JavaScript, C++ va SQL uchun tayyor andozalar.
- **Dev Asboblar** — JSON formatlagich, Base64 konverteri, xavfsiz token
  generatori va RegEx tekshirgichi.
