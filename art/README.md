# art/

Standalone artwork, unrelated to the trading strategy in the repo root.

- `scene.json` — the written scene brief this was built from.
- `cosmic-book-scribe.html` — "Scriptorium of the Starfall": the brief rendered as a
  concept plate. The painting is procedural canvas (no image files); the page keys
  eight callouts to positions in the frame, so hovering or focusing a key lights the
  matching reticle on the painting.

Open the HTML file directly in a browser, or publish it as an artifact.
